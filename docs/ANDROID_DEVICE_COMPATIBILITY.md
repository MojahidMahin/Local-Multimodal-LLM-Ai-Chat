## Reporting Compatibility Issues

If you encounter issues on your device:

1. **Check this matrix first**
2. **Verify minimum requirements**
3. **Try recommended model for your device**
4. **Report issue with:**
   - Device make and model
   - Android version
   - RAM amount
   - Processor type
   - What doesn't work
   - Logcat if possible

**Create issue:** GitHub Issues with "Device Compatibility" label
